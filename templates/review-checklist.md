# Review Checklist

成果物の完成宣言前に使用する共通チェックリストです。

案件固有の完成条件は、各案件の`planning.md`を優先します。

## 1. 内容レビュー

- [ ] 目的と想定読者に合っている
- [ ] 中心メッセージが一貫している
- [ ] 各ページ・各章・各シートの役割が明確
- [ ] 数値、日付、固有名詞が確認済み
- [ ] 本人の体験と外部仕様を区別している
- [ ] 参照資料にない情報を推測で補完していない
- [ ] 不要な一般論、重複、制作過程の説明がない
- [ ] 掲載しない情報が混入していない
- [ ] `planning.md`と成果物が一致している

## 2. 修正後の二次影響

- [ ] 修正した箇所を確認した
- [ ] 同じ要素内の他の文章・数式・図形を確認した
- [ ] 隣接する要素への影響を確認した
- [ ] 改行、余白、配置、ページ端との距離を確認した
- [ ] 別ページ・別シート・別成果物への影響を確認した
- [ ] `planning.md`へ変更を同期した

## 3. Googleスライド

- [ ] 全ページをサムネイルまたはPDFで確認した
- [ ] 文字や図形がスライド領域からはみ出していない
- [ ] 助詞や語尾だけの不自然な改行がない
- [ ] 見出しと本文の強弱が明確
- [ ] カードの幅、高さ、間隔が揃っている
- [ ] 図形、線、矢印が不自然に重なっていない
- [ ] 文字サイズを下げるだけで問題を隠していない
- [ ] ファイル名、ページ番号、タイトルが適切

## 4. Qiita向けMarkdown

- [ ] 本文をQiitaエディタへそのまま貼り付けられる
- [ ] HTMLコメントにタイトル案・タグ候補・未投稿状態がある
- [ ] 本文にQiitaタイトル欄と重複するH1を残していない
- [ ] 見出し階層が正しい
- [ ] 箇条書き、表、コードブロック、リンクが成立している
- [ ] 画像URLが公開環境から参照できる
- [ ] Google Drive限定URLや仮URLが残っていない
- [ ] 個人情報、社内情報、機密情報が含まれていない
- [ ] 投稿や下書き登録を自動で行っていない

## 5. 複数成果物

- [ ] 事実、数値、日付、固有名詞が一致している
- [ ] 用語と中心メッセージが一致している
- [ ] 各形式に適した情報量へ再編集されている
- [ ] 元成果物の単純な文字起こしになっていない
- [ ] 一方で削除した情報が、もう一方へ不自然に残っていない
- [ ] 主成果物と派生成果物の進捗を分けて管理している

## 6. 最終QA

- [ ] 未解決事項がない、または許容判断が記録されている
- [ ] ファイル名と保存場所が正しい
- [ ] 成果物へのリンクが正しい
- [ ] 確認できていない項目を明示している
- [ ] 過剰な修正を続けず、価値が上がる変更だけを行った
- [ ] ユーザーが完成形として承認した
